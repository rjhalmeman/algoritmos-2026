Dados em Memória RAM (em vetor com dados heterogêneos)

A RAM é a memória de trabalho, ou seja, temporária. Um vetor (ou array) heterogêneo é uma lista na RAM capaz de guardar diferentes tipos de dados misturados na mesma estrutura — por exemplo, armazenar um texto (nome do filme), um número inteiro (ano) e um objeto na mesma lista enquanto o programa está rodando. Se o programa fechar, esses dados somem.

Arquivo (ou documento)
É um conjunto de dados gravado de forma permanente no armazenamento do dispositivo (HD, SSD, pen drive). Diferente da memória RAM, a informação contida em um arquivo não é apagada quando o computador é desligado.

Extensão de um arquivo (.txt, .csv, .jpeg, .docx, .pdf)
São as letras finais no nome de um arquivo, logo após o ponto. Elas funcionam como uma "etiqueta" que indica para o sistema operacional qual é o formato daquele arquivo e qual software deve ser acionado para traduzir e exibir os dados corretamente.

Arquivo CSV (Comma-Separated Values)
É um arquivo de texto simples usado para representar dados em formato de tabela (linhas e colunas). Cada linha do arquivo é um registro, e as colunas são separadas por um caractere específico, geralmente uma vírgula (,) ou ponto e vírgula (;). É o padrão universal para importar e exportar dados de forma leve.

Persistência (salvar o arquivo)
É o ato de garantir que a informação sobreviva ao fim da execução do programa. Consiste em pegar os dados temporários que estão na memória RAM (como o seu vetor de filmes) e gravá-los fisicamente no disco rígido na forma de um arquivo.

Recuperar dados (abrir o arquivo)
É o processo inverso da persistência. Consiste em acessar o armazenamento permanente (o disco), ler o arquivo que foi salvo e carregar suas informações de volta para as variáveis ou vetores na memória RAM, permitindo que o programa volte a manipular esses dados.
